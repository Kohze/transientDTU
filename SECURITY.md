# Security policy

Please do not open a public issue for a vulnerability that could expose data,
execute unintended code, or compromise a user's environment. Email
robin@kohze.com with the affected version, a minimal reproduction, and the
potential impact. Do not include sensitive study data.

The maintained development version is `main`; after release, the current
Bioconductor release branch will also receive security fixes. Methodological
errors without a security consequence should use the ordinary support channel.

# AI assistance provenance

The initial package engineering, documentation, and test scaffolding were
developed with assistance from OpenAI Codex. The scientific decision rule was
derived from the authors' existing doctoral-analysis and manuscript code.

The package maintainer reviewed, tested, and accepts responsibility for all
distributed code. No third-party source code was copied into the package.
This disclosure is included to satisfy the Bioconductor policy for non-trivial
AI-assisted contributions.
